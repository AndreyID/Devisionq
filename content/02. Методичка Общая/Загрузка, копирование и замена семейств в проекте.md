# Загрузка семейства с заменой вложенных общих семейств

При работе с семействами может возникнуть ситуация, когда отличаются вложенные общие семейства в главном семействе и их нужно заменить.

Выбираем семейство → Редактировать семейство → Загрузить в проект → 
Выбираем другой проект → Заменить существующую версию → 
Заменить общее семейство подчиненных компонентов вместе со значениями параметров версией семейства
![[../resources/04. Методичка АР/АР_49.jpg]]![[../resources/04. Методичка АР/АР_50.jpg]]![[../resources/04. Методичка АР/АР_53.jpg]]
![[../resources/04. Методичка АР/АР_52.jpg]]

> [!warning]
>Не **рекомендуется** копировать семейства из проекта в проект с помощью **Ctrl+C** **Ctrl+V**. При этом способе семейство копируется в проект но не заменяется. Создается копия аналогичного семейства но с **индексом _1, _2, _3 ...** При током способе неизбежно засоряется модели и работать с файлом становится труднее.
