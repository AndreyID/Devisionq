Для управления элементами, доступными для выбора, и режимом выбора используйте следующие параметры. Выбор этих параметров описан ниже:  

- На ленте в инструменте "Изменение" нажмите кнопку "Выбрать" для перехода к раскрывающемуся меню.

![[../resources/Выбор элементов/Выб_1.webp]]

- Щелкните значок в правом нижнем углу строки состояния.

![[../resources/Выбор элементов/Выб_2.webp]]

## "Выбрать связи" ![[../resources/Выбор элементов/Выб_3.png]]

Параметр "Выбрать связи" используется для выбора связанных файлов и отдельных элементов в связях.  
Связанные файлы могут включать следующие элементы:  

- модели Revit;
- файлы САПР.
- Облака точек

Для выбора связанного файла целиком и всех его элементов наведите курсор на связь, чтобы выделить ее, и щелкните мышью.  
Для выбора отдельного элемента в связанном файле наведите курсор на элемент, нажмите клавишу TAB для его выделения и щелкните мышью.  
Если возможность выбора связей и их элементов противоречит возможности выбора элементов в проекте, отключите данную функцию. Если функция "Выбрать связи" не выбрана, можно по-прежнему привязывать и выравнивать элементы в связях.

## "Выбрать фоновые элементы"![[../resources/Выбор элементов/Выб_4.png]]

Функция "Выбрать фоновые элементы" используется для выбора элементов, содержащихся в подложке.  
Если возможность выбора фоновых элементов противоречит возможности выбора элементов на виде, отключите данную функцию. Если функция "Выбрать фоновые элементы" не выбрана, можно по-прежнему привязывать и выравнивать элементы в подложке.

## "Выбрать закрепленные элементы"![[../resources/Выбор элементов/Выб_5.png]]

Функция "Выбрать закрепленные элементы" используется для выбора элементов, закрепленных в определенном положении, которые не могут быть перемещены.  
Если возможность выбора закрепленных элементов противоречит возможности выбора других элементов на виде, отключите данную функцию. Например, требуется исключить закрепленные элементы из выбора секущей рамки.

## "Выбрать элементы по граням"![[../resources/Выбор элементов/Выб_6.png]]

Функция "Выбрать элементы по граням" используется для выбора элементов с помощью щелчка на внутренних гранях вместо ребер. Например, она позволяет выбрать стену или перекрытие с помощью щелчка мышью в центре элемента.  
Когда эта функция включена, она применяется ко всем видам модели и узлов. Однако она не применяется в случае выбора визуального стиля вида "Каркас".  
Если эта функция отключена, для выбора элемента щелкните по его ребру.

## "Перетащить элементы на выделение"![[../resources/Выбор элементов/Выб_7.png]]

Функция "Перетащить элементы на выделение" используется для перетаскивания элемента без предварительного выделения.  
Во избежание случайного перемещения элемента при выборе можно отключить эту функцию.  
Эта функция применяется к элементам во всех категориях модели и аннотаций.

## Примечания об использовании

- Эти функции применяются ко всем открытым видам; они не являются специфичными для вида.
- При необходимости их можно включить и отключить в любой момент во время текущего сеанса.
- Параметры каждого пользователя для этих функций сохраняются до следующего сеанса работы.
