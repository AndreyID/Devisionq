# Создать ограждения в Revit можно тремя способами

— Системным ограждением
— Семейством, например обобщенной моделью
— Витражом
У каждого из вариантов есть свои преимущества и недостатки. Разберем их для каждого варианта.
## Системное ограждение

Плюсы
- Возможность непрерывно вести линию
- Автоматически подстраивается под рельеф
- Быстро работает
Минусы
- Плохо работает с примыканиями
- Могут создаваться искажения в примыканиях, нужно отслеживать и редактировать эти моменты
- Нет возможности использовать доборный отрезок в конце
- Изменения происходят только в редактировании элемента
- Нужно соблюдать шаг, чтобы в ограждении создавались примыкания и не было разрывов

![[Благо_19.jpg]]

## Семейство

Плюсы
- Есть ползунок для работы в 3D
- Есть возможность сделать примыкание отрезков под углом
- Есть возможности использовать доборный отрезок в конце
- Есть возможность настраивать высоту конечного отрезка под рельеф
- Есть возможность отключения конечной стойки для примыкания со следующей секцией
- Быстро работает
Минусы
- Каждый отрезок это отдельный элемент
- У каждого отрезка нужно настраивать высоту конечной секции под рельеф

![[Благо_20.jpg]]

## Витраж

Плюсы
- Есть возможность работать в 3D
- Есть возможность сделать примыкание отрезков под углом
- Есть возможности использовать доборный отрезок в конце
- Возможность непрерывно вести линию, но это отдельные отрезки
- Есть возможность вставить дополнительные элементы разрезав витраж, например калитку или забор, но тогда нужно учитывать размер вставляемых элементов
Минусы
- Не подстраивается под рельеф в принципе
- Если вставляешь элементы Калитка или Ворота в виде витража, то нужно следить за его фактическими размерами

![[Благо_21.jpg]]

## Калитка и ворота

Для Семейств категории `Обобщенные модели` и `Витраж` доступные элементы Калитка и Ворота. Данные экземпляры — элементы с фиксированными размерами, созданные по аналогу из каталога в благоустройстве. Также есть возможность сделать их масштабируемыми по высоте и длине.

![[Благо_22.jpg]]

У моделей есть возможность выбрать сторону открывания:
- Внутрь
- Наружу
- Слева
- Справа
У калитки можно отключить стойки

# Работа с ограждениями

Во всех вариантах есть начальная, конечная точка размещения ограждения и ее направление. По направлению определяется где будет расставлена доборная секция. По умолчанию она создается в конце отрезка.

![[Благо_23.jpg]]

Чтобы создать симметричный забор, сначала расставьте забор с калиткой, после расставьте ограждения по краям от входа.

![[Благо_24.jpg]]

## Если работаете с семейством

Выровняйте ограждение и отключите первую стойку

![[Благо_25.jpg]]

## Если работаете с витражом

Далее стыкуйте ограждения с калиткой / воротами. При этом можно удалить (предварительно отсоединив) стойку у витража, чтобы создать примыкание с обоих сторон

![[Благо_26.jpg]]

## Настройка стоек

- Ограждение
Настроить стойки можно в свойствах ограждения. 
Одна стойка находится в массиве с ограждением, а другая либо а начале, либо в конце ограждения.

![[Благо_27.jpg]]

Их можно настроить как в заполнении, так и в стойках.

![[Благо_28.jpg]]

- Семейство
Настроить стойки можно в свойствах во вкладке "Строительство" ограждения.

![[Благо_29.jpg]]

- Витраж
В витражных панелях стойки сделаны из импостов. Чтобы редактировать стойку выделите ее и открепите. Теперь вы можете ее либо поменять, либо удалить.

![[Благо_30.jpg]]

У витражей есть особенность. У них есть возможность создать угловое примыкание. Для это выберите импост в угловом примыкании и замените на угловой. Вам предложат удалить соседний импост. Выбираем "Удаление элементов" и угловое примыкание готово.
