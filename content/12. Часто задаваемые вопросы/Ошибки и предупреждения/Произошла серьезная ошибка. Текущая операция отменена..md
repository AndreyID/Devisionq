# Cимптомы

**При попытке сделать проверку на пересечения со связанным файлом возникает ошибка.**  
  
- Текст ошибки: "Произошла серьезная ошибка. Текущая операция отменена. Перед продолжением настоятельно рекомендуется сохранить результаты работы в новом файле. Сохранить файл восстановления?".
- Текст ошибки eng: "A serious error has occurred. The current action has been cancelled. It is strongly recommended that you save your work in a new file before continuing. Would you like to save a recovery file?"

![[../../resources/12. Часто задаваемые вопросы/Ошибки и предупреждения/Ош_90.webp]]
# Возможные причины

- Связанный файл содержит в себе другой связанный файл с типом связи "Прикрепление".
- В связанном файле отсутствуют элементы соответствующей категории, с которой осуществляется проверка. Например, "Стены".
# Решение #1 - Изменить тип связи

1. Откройте связанный файл, с которым необходимо произвести проверку.
2. На вкладке "Управление" в "Диспетчере связей" измените тип связи файла на "Наложение".

![[../../resources/12. Часто задаваемые вопросы/Ошибки и предупреждения/Ош_91.webp]]
# Решение #2 - Добавить элементы

Добавьте в связанный файл элементы соответствующей категории, с которой осуществляется проверка. Например, "Стены".
