# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Начало экземпляра не лежит на грани основы. Будет разорвана связь экземпляра с основой."
- Текст ошибки eng: "Instance origin does not lie on host face. Instance will lose association to host."

![[Ош_31.webp]]
# Возможные причины

При обновлении связи в Revit семейства на основе граней, такие как электрические компоненты, освещение и устройства безопасности и прочие, если были размещены по элементам связи, теряют свою основу, и смещаются.
# Решение - Переназначить основу

Переназначьте основу для семейств:

1. Выберите семейство.
2. Выберите на ленте команду "Редактировать рабочую плоскость".
3. Переназначьте основу для семейства на уровни или иной системный элемент из вашего проекта.

![[Ош_32.webp]]

4. Обновите связь.
