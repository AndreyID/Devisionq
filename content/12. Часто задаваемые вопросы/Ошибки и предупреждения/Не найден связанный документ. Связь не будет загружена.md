# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Не найден связанный документ ...rvt. Связь не будет загружена."
- Текст ошибки eng: "Cannot open linked document ....rvt. The link will be unloaded."

![[../../resources/12. Часто задаваемые вопросы/Ошибки и предупреждения/Ош_33.webp]]
# Возможные причины

1. Связанный файл поврежден.
2. Не доступен сервер или папка, в которой расположен связанный файл.
3. Связанный файл отсутствует в папке проекта.
# Решение #1 - Обновить связь

4. Откройте диспетчер связей, проверьте статус связанного файла.
5. Обновите связь, выбрав “Обновить из”, при отсутствии изменений.
# Решение #2 - Перезагрузить связь

1. Удалите связь из диспетчера.
2. Загрузите связь повторно.
