# Локальные файлы Revit 
## Перенос локальных файлов
Revit по умолчанию создает локальные копии в Документах на диске C
Можно исправить это и сделать так чтобы Revit переносил на другой диск или другое место

Файл → Параметры → Файлы → Путь по умолчанию для пользовательских файлов → Обзор → Выбираем путь и создадим там папку **Локальные файлы**
## Удаление локальных файлов
Файл → Параметры → Файлы, в окне "Путь по умолчанию для пользовательских файлов" указан путь, где хранятся локальные копии

Чистите раз в неделю, чем больше файлов удалите, тем лучше

Удаляем как локальный файл так и папку с таким же названием и окончанием `_backup`

# Системная очистка
## Windows 10
Инструкция для версии 1809 и новее:
1. Нажмите `Пуск` → `Параметры` (значок шестеренки) → **Система**.
2. Выберите вкладку **Хранилище**.
3. Здесь вы увидите план вашего диска C: Чтобы активировать авточтистку, передвиньте ползунок **«Контроль памяти»** в положение **Вкл.**
4. 
- Чтобы настроить параметры удаления, нажмите на синюю ссылку **Изменить способ освобождения места**.
- Для немедленной ручной очистки нажмите кнопку **Освободить место сейчас** — это аналог удаления временных файлов в Windows 11
## Windows 11 
Интерфейс в «одиннадцатой» версии самый наглядный. Вот пошаговая инструкция:
1. Нажмите `Win + I`, чтобы открыть **Параметры**.
2. Перейдите в раздел **Система → Память**.
3. **Быстрая очистка**: Нажмите на строку **«Временные файлы»**. Система просканирует диск и покажет список мусора (кэш системы, эскизы, старые обновления). Просто отметьте нужные пункты и нажмите **Удалить файлы**.
4. **Автоматическая настройка**: Включите тумблер **«Контроль памяти»** и нажмите на него левой кнопкой мыши, чтобы открыть расширенные настройки. Здесь вы можете сами выбрать, когда и что именно система должна чистить в фоновом режиме.

> [!info]
>1. **Осторожнее с папкой «Загрузки»**: Если вы привыкли хранить важные документы в папке «Загрузки» (а многие так делают), **обязательно** проверьте настройки. Убедитесь, что в параметрах «Контроля памяти» для этой папки стоит значение **«Никогда»**. Иначе система может удалить нужные вам установочные файлы или счета .
>2. **Зарезервированное место**: Не пугайтесь, если система показывает пункт «Зарезервированное системой место» — Windows просто держит про запас немного места для обновлений и кэша. Контроль памяти сам решает, что с этим делать .  
>3. **Другие диски**: Встроенный контроль памяти работает **только** с системным диском C:. Если вы хотите почистить диск D или флешку, придется делать это вручную (например, через свойства диска → «Очистка диска»)
# Временные файлы 
## Папка Temp
Папку **Temp** можно и нужно чистить — это абсолютно безопасно и очень эффективно для освобождения места на диске. Все файлы в ней — временные, и если программа или система уже завершила работу, они больше не нужны.

Файлы, которые сейчас используются системой, Windows просто не даст удалить — их можно смело пропускать. Остальное будет удалено без вреда для ПК.

Самый быстрый ручной способ:
1. Нажмите **`Win + R`** (клавиша с логотипом Windows и английская буква R).
2. Введите команду **`%temp%`** и нажмите `Enter` .
3. Выделите все файлы (`Ctrl + A`) и нажмите `Delete` .
