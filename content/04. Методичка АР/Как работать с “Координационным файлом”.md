#базаЗнаний #АР

Координационный файл создается на основе шаблона `Dv_Шаблон_АР(АС)`

Файл в себе содержит только оси и уровни секций, разбитые по рабочим наборам. Подготавливается он Bim отделом.

В модели секций подгружается “Координационный файл” ссылкой. Из него с помощью “Координация / мониторинг” переносятся оси и уровни конкретной секции.

Совместная работа → Копирование/мониторинг → Выбрать связь
Выбираем Координационный файл

Копировать → Несколько
Выбираем нужные нам оси на плане
Готово → Готово

Повторяем тоже самое с уровнями на разрезе или фасаде

> [!info]
>Оси и уровни меняются только в координационном файле

Все оси и уровни меняются исполнителем только через “Координационный файл” путем их смещения (удалять их и создавать им замену нельзя). После того как исполнитель осуществит изменения в “Координационном файле” все участники, которые работают с моделями по данной секции, увидят изменения осей и уровней. С помощью “Координация / мониторинг” смогут автоматически устранить различия между осями и уровнями своего проекта и проекта “Координационный файл”
