# Наименование вида имеет следующий порядок

`[ 0 ]` — Тип окна: **(Вн) - внутреннее, (Н) - наружное, (Вн) / (Н)**

`[ 1 ]` — Категория Окно / Дверь: **( ) - окно, д - дверь, ( ) / (д)**

`[ 2 ]` — Количество створок по горизонтали (→) и вертикали (↑)**

`[ 3 ]` — Размер: **LxH(h) 1360х1800(h)**

`[ 4 ]` — Тип нижней створки: **Г-Г0**

`[ 5 ]` — Тип верхней створки с высотой: **ЛО-ПО(h)**

`[ 6 ]` — Проставочный профиль, **В**ерх или **Н**из и его высота:

**(пр_В 60) / (пр_Н 60) / (пр_Н 60 пр_В 60)**

Пример:

## **Одностворчатое**  
ВН__д__1-2__800х1800(h)__дПО__Г(450)  
`[ 0 ]` Внутреннее  
`[ 1 ]` Дверь  
`[ 2 ]` С 1 створкой по горизонтали и 2 по вертикали  
`[ 3 ]` Размером 800 в ширину и 1800 в высоту (размер изделия, параметры вы типе: Ширина и Высота)  
`[ 4 ]` С **правой откидной** створкой, на плане обозначается как дверь  
`[ 5 ]` Верхняя створка высотой (**450**), **глухая**

**— — — — — — — — — — — — — — — — — —**

## **Двухстворчатое**  
Н__2-1__2800х3000(h)__ЛО-Г  
`[ 0 ]` Наружное  
`[ 2 ]` С 2 створками по горизонтали и 1 по вертикали  
`[ 3 ]` Размером 2800 в ширину и 3000 в высоту (азмер изделия, параметры вы типе: Ширина и Высота)  
`[ 4 ]` С Левой откидной и глухой створкой  
**— — — — — — — — — — — — — — — — — —**

## **Трехстворчатое**  
ВН__3-2__2900х1800(h)__Г-Г-Г__О-О-О(450)  
`[ 0 ]` Внутреннее  
`[ 2 ]` С 3 створками по горизонтали и 2 по вертикали  
`[ 3 ]` Размером 2900 в ширину и 1800 в высоту (азмер изделия, параметры вы типе: Ширина и Высота)  
`[ 4 ]` С тремя **глухими** створками  
`[ 5 ]` Верхние створки высотой (**450**) состоят из стрех **откидных** створок

# Редактируемые параметры в типе:

Если отключить “Ригель горизонтальный”, 2. Тип створки будет крыт

![](../../resources/04.%20Методичка%20АР/Окна/Окна_1.png)

Если включить“Ригель горизонтальный”, 2. Тип створки будет отображаться сверху

![](../../resources/04.%20Методичка%20АР/Окна/Окна_2.png)

Чтобы изменить параметры воспользуйтесь параметром “Высота”, “Ширина”.

![](../../resources/04.%20Методичка%20АР/Окна/Окна_3.png)

Параметр “Дверь скрытие” создает обл. маскировки и скрывает окно на плане.

![](../../resources/04.%20Методичка%20АР/Окна/Окна_4.png)

У каждой створки есть ригель. При выборе типа створки ригель может отображаться и может быть скрыт. В данном примере, в каждой створке был выбран тип с ригелем (обозначается буквой “р”).

![](../../resources/04.%20Методичка%20АР/Окна/Окна_5.png)

“Ригель_низ” отвечает за ригель по горизонтали ”Створка справа” отвечает за ригель по вертикали

![](../../resources/04.%20Методичка%20АР/Окна/Окна_6.png)

Вы можете выбрать тип окна

![](../../resources/04.%20Методичка%20АР/Окна/Окна_7.png)

Добавляет проставочный профиль сверху

![](../../resources/04.%20Методичка%20АР/Окна/Окна_8.png)

Добавляет проставочный профиль снизу
