# 1.Проверка помещений

Спецификация для удаления "Не размещенных"и проверки "Не окруженных" помещений.

---

# 2.1. Заполнение данных (Тип квартиры)

В спецификации отображаются все наименования Квартир из **ADSK_Тип квартиры**

---

# 2.2. Заполнение данных (Тип помещения для не квартир)

В спецификацию попадают все нежилые помещения с **ADSK_Тип квартиры = 0**

---

# 2.3. Заполнение данных (Тип помещения, Номер)

Спецификация для квартир. Главный параметр в спецификации **ADSK_Тип_помещения.**

Его заполнение происходит следующим образом: 1 - жилое комнаты 2 - с/у, ванная, кухня, прихожая 3 - холодная лоджия, теплая лоджия 4 - балкон, терраса

---

# 3. Заполнение данных (Номер квартиры, Тип квартиры)

Спецификация для проверки параметра **ADSK_Номер квартиры**

---

# 4.1. ПРОВЕРКА (Тип квартиры)

После запуска Плагина "Квартирография", все фиолетовые колонки должны быть заполнены, если нет, тогда площади не совпадают, Для проверки открывать спецификацию "5.3. ПРОВЕРКА/ПОИСК...." в фильтре прописать первые два символа типа квартиры (без строчной буквы), найти отличие в площадях.

---

# 4.2. ПРОВЕРКА (Тип квартиры, одна площадь разные квартиры)

После запуска Плагина "Квартирография", проверяем "ADSK_Тип квартиры”

---

# 4.3. ПРОВЕРКА/ПОИСК (Тип квартиры, строчная буква)

В фильтре "ADSK_Тип квартиры" - "начинается с" - пишем первые два символа типа квартиры (без строчной буквы) и анализируем площади. Для одного типа квартиры должна совпадать площадь по всем фиолетовым столбцам, вносим корректировки "ADSK_Тип квартиры" (третьим символом - строчной буквой от верхнего этажа к нижнему)
