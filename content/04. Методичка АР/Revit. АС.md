**Путь:** Вкладка **Вид** → **Виды в плане** → **План этажа**

![[АС_17.png]]

![[АС_19.png]]

Выбираем необходимые **Планы этажей**

![[АС_18.png]]

## 1.2. Разрезы

**Путь:** Вкладка **Вид** → **Создать** → **Разрез**

![[АС_22.png]]

**Порядок действий:**

1. Выбираем подходящий **Типоразмер** разреза.

![[АС_23.png]]

2. На плане укажите первую точку (начало секущей плоскости).

3. Укажите вторую точку (конец секущей плоскости).


**Обозначение разреза:**  
Дважды щелкните по обозначению разреза, чтобы перейти к виду разреза. Переименуйте вид по стандарту (например, «Разрез 1-1»).

## 1.3. Фрагмент


![[АС_24.png]]
### Фрагмент

**Фрагмент** используется для предоставления дополнительной информации о части исходного вида в **более крупном масштабе**. Это помогает выстроить логичную цепочку документации: от общих планов к более детальным чертежам.

![[АС_26.png]]
### Вид узла

**Вид узла** — это инструмент для **деталировки**. Он позволяет показать, как именно устроен тот или иной конструктивный элемент (например, вентшахта, узел стены, крепление окна, свес крыши), с помощью 2D-линий и компонентов.

![[АС_25.png]]
## 1.4. Шаблон вида

Шаблон вида — это набор предварительно настроенных параметров отображения (масштаб, уровень детализации, видимость категорий, подрезка, параметры графики), который применяется к виду одним щелчком. Шаблоны экономят время и обеспечивают единообразие оформления всех планов, разрезов и узлов.

После создания рабочих видов, каждому из них назначается **Шаблон вида** из подготовленных в шаблоне

# 2. Перемычки

## 2.1. Типы перемычек: обзор

**Краткое описание:**  
Перемычки в Revit моделируются с использованием подгруженных семейств. В проектировании применяются различные конструктивные решения в зависимости от материала стены, ширины проема и наличия вышележащих нагрузок.

**Пример названия семейства:**  
`03.8_ПеремычкаСоставная_2Уголка`

**Список вложенных семейств:**
`03_Уголок равнополочный_ГОСТ 8509-93`
`03_ПластинаСтальная`

![[АС_7.png|400]]

Полное описание всех перемычек можно посмотреть в [[АР АС. Перемычки|статье]].

## 2.2. Расстановка перемычек

### Ручная расстановка:

1. Откройте план этажа, где требуется установить перемычку.

2. Вкладка **Конструкция** → **Балка** → **Разместить компонент**.

3. Выберите семейство перемычки из списка типов.

4. Укажите курсором на проем .

5. Установите перемычку, проверьте ее положение на разрезе или в 3D виде.

### Расстановка с помощью плагина:

- [[Инструкция по установке плагинов для AutoCAD и Revit|Установка плагина]]

- [[../10. Плагины и приложения/Перемычки|Работа с плагином Перемычки]]

## 2.3. Основные параметры для заполнения

### Основное семейство:

| Параметр       | Тип      | Назначение                                    |
| -------------- | -------- | --------------------------------------------- |
| Dv_Марка       | Тип      | Марка перемычки (например, **Пр-1**)          |
| Dv_Номер этажа | Экземляр | Номер этажа, на котором расположена перемычка |
| LintelImage    | Экземляр | Изображение (графическое представление)       |
### Вложенное семейство:

| Параметр       | Тип      | Назначение                     |
| -------------- | -------- | ------------------------------ |
| Марка          | Тип      | Позиция в спецификации         |
| Dv_Номер этажа | Экземляр | Номер этажа                    |
| Dv_Марка       | Экземляр | Связанна с основным семейством |

## 2.4. Разбор спецификаций

### Спецификация: Основное семейство

**Диспетчер проекта** → **Ведомости/Спецификации** → **АС**

`АС_Р_Перемычки_Ведомость (поэтажная)`

**Настройка:**

- Категория: Каркас несущий

- Фильтр: 
  `Группа модели` равно «Перемычки составные»
  `Тип` не содержит «пм»
  
- Поля: `Dv_Марка`, `Dv_Номер этажа`, `LintelImage`

### Спецификации: Вложенное семейство

**Диспетчер проекта** → **Ведомости/Спецификации** → **АС** → **Перемычки**

`АС_Р_Перемычки_(поэтажная)Детали`
`АС_Р_Перемычки_(поэтажная)ЖБ`
`АС_Р_Перемычки_(поэтажная)Металл`

**Настройка:**

- Категория: Каркас несущий

- Фильтр: 
  `Группа модели` равно «Перемычки»
   
- Поля: `Марка`, `Обозначение`, `ADSK_Наименование`, `Наименование`,  `Dv_Номер этажа`, `ADSK_Обозначение`
