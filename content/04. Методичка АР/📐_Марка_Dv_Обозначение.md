# Для корректного обозначения заполняется параметр - Dv_Обозначение

## 1. Проверка наличия параметра в проекте

Открыть `[Параметры проекта]` на вкладке `[Управление]`

![[АР_2.jpg]]

В поиске по имени параметра ввести: Dv_Обозначение

![[АР_3.jpg]]

Если параметр есть в проекте -> сравнить настройки с пунктом 4 Если такого параметра нет, его нужно добавить. Для этого:

1. Нажать кнопку добавления нового параметра

![[АР_4.jpg]]

2. Поставить галочку - `[Общий параметр]` и нажать кнопку `[Выбор]`

![[АР_5.jpg]]

3. В открывшемся окне выбрать из списка параметр `[Dv_Обозначение]` из группы параметров `[001 Dv Общие]` и нажать `[ОК]`

![[АР_6.jpg]]
4. В свойствах параметра поставить галочку `[Значения могут изменяться по экземплярам группы]`. Выбрать категории - Лестницы, Обобщенные модели, Специальное оборудование, Шкафы. Нажать кнопку `[ОК]`

![[АР_7.jpg]]
## 2. Заполнение параметра

После добавления/настройки параметра, он будет доступен для заполнения в настройках экземпляра -> Подкатегория `[Текст]`
