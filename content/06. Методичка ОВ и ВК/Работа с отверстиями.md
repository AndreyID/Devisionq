# Создание отверстий

Перед расстановкой отверстий обязательно нужно переключить рабочий набор на "Отверстия"

![[../resources/ОВВК/ОВВК_2.jpg]]

Теперь можно начинать работать с отверстиями. Переходим DEVISION → КОНСТРУКЦИИ → Отверстия

![[../resources/ОВВК/ОВВК_3.jpg]]

- Выбираем Связанный файл стен, перекрытий (файл АР, из которого будут браться стены, перекрытия)

![[../resources/ОВВК/ОВВК_4.jpg]]

- Строку Связанный файл коммуникации пропускаем
- Ставим галочку "В стенах" и выбираем Уровень (галочку "в выбранных" желательно не использовать)

![[../resources/ОВВК/ОВВК_5.jpg]]

- Выбираем нужный Материал стен, в которых будут стоять отверстия. Для перекрытий материал выбирать не нужно

![[../resources/ОВВК/ОВВК_6.jpg]]

- По необходимости можно поменять значения данных параметров

![[../resources/ОВВК/ОВВК_7.jpg]]

- В "Назначение" указываем `Раздел_Номер` секции (`_1`, для отверстий выше 0.000) и нажимаем "РАССЧИТАТЬ"

![[../resources/ОВВК/ОВВК_8.jpg]]

Нажимаем везде "Да"

![[../resources/ОВВК/ОВВК_9.jpg]]

Нажимаем "ОК"

![[../resources/ОВВК/ОВВК_10.jpg]]

Дальше появляется список отверстий, теперь нажимаем "Создать" для того, чтобы они появились в проекте

![[../resources/ОВВК/ОВВК_11.jpg]]

Нажимаем "ОК"

![[../resources/ОВВК/ОВВК_12.jpg]]

Если нужно сразу посмотреть какое-то отверстие из списка, нужно для начала открыть 3D вид, а затем нажать на нужную строку

![[../resources/ОВВК/ОВВК_13.jpg]]

И тогда на 3D виде отобразиться данное отверстие

![[../resources/ОВВК/ОВВК_14.jpg]]

> [!info]
>Для дальнейшей расстановки отверстий нужно закрыть окно плагина и открыть заново!
# Заполнение высотных отметок

Для заполнение высотных отметок нужно воспользоваться скриптом Dynamo. Переходим Управление → Визуальное программирование → Dynamo

![[../resources/ОВВК/ОВВК_15.jpg]]

- Нажимаем "Открыть"

![[../resources/ОВВК/ОВВК_16.jpg]]

- Вставляем путь к скрипту: \\192.168.22.113\проекты\Библиотека Devision\06_BIM\Шаблон_КР\Скрипты\Отверстия

И выбираем "`Dv_Высотные отметки_Отверстия.dyn`"

![[../resources/ОВВК/ОВВК_17.jpg]]

- Нажимаем "Открыть"

После загрузки нажимаем "Запуск"

![[../resources/ОВВК/ОВВК_18.jpg]]

После завершения процесса закрываем окно Dynamo без сохранения.

![[../resources/ОВВК/ОВВК_19.jpg]]
# Заполнение параметра ADSK_Позиция

Открываем спецификацию `Проверка_Спецификация_Отверстия_Стены` или `Проверка_Спецификация_Отверстия_Перекрытия`

![[../resources/ОВВК/ОВВК_20.jpg]]

Переходим в ModPlus → Утилиты → Нумерация

![[../resources/ОВВК/ОВВК_21.jpg]]

- Вводим начальное значение 1, шаг 1, целевой параметр `ADSK_Позиция` (если не заполнено). И нажимаем "Выполнить"

![[../resources/ОВВК/ОВВК_22.jpg]]
# Создание планов этажей

Переходим в Вид → Создание → Виды в плане → План этажа

![[../resources/ОВВК/ОВВК_23.jpg]]

- В Типе выбираем `Задание_В_ПЭ_Отверстия`

![[../resources/ОВВК/ОВВК_24.jpg]]

Выбираем необходимый уровень и нажимаем "ОК"

![[../resources/ОВВК/ОВВК_25.jpg]]

Виды делятся на проверочные (проверка отверстий и коммуникаций) и те, которые выводятся на лист

**1. Создание проверочных планов**

В Свойствах к "Имя вида" добавить _Отверстия. Затем нажать на "Шаблон вида"

![[../resources/ОВВК/ОВВК_26.jpg]]

Выберите один из выделенных шаблонов и нажмите "ОК"

![[../resources/ОВВК/ОВВК_27.jpg]]

**2. Создание планов на лист**

Чтобы создать план этажа на лист можно скопировать существующий вид проверки

![[../resources/ОВВК/ОВВК_28.jpg]]

Нужно переименовать скопированный вид вместо копия 1 добавить `_Стены` или `_Перекрытия`

![[../resources/ОВВК/ОВВК_29.jpg]]

Пример: "`-01_-3.150_Подвал_Отверстия копия 1`" → "`-01_-3.150_Подвал_Отверстия_Стены`"

Затем нажимаем на "Шаблон вида" и выбираем один из выделенных шаблонов и нажимаем "ОК"

![[../resources/ОВВК/ОВВК_30.jpg]]
# Расстановка марок

Переходим Аннотации → Маркировать все

![[../resources/ОВВК/ОВВК_31.jpg]]

Ставим галочку возле Марки обобщенной модели. Выбираем одну из выделенных марок.

> [!info]
>Обязательно проверьте, чтобы была галочка на выноска!

![[../resources/ОВВК/ОВВК_32.jpg]]
# Вывод планов/спецификаций на лист

В Диспетчере проекта нажать на Листы правой кнопкой мышки и выбрать "Новый лист..."

![[../resources/ОВВК/ОВВК_33.jpg]]

Выбрать в основных надписях "нет" и нажать "ОК"

![[../resources/ОВВК/ОВВК_34.jpg]]

В `ADSK_Штамп` Раздел проекта написать/выбрать - Отверстия

![[../resources/ОВВК/ОВВК_35.jpg]]

В диспетчере проекта найти нужный план этажа/ спецификацию, зажав левую кнопку мышки перенести на лист

![[../resources/ОВВК/ОВВК_36.jpg]]

Либо переходим в Вид → Композиция листов → Разместить вид. Выбираем нужный и нажимаем "ОК"

![[../resources/ОВВК/ОВВК_37.jpg]]

Чтобы появилось наименование плана нужно выбрать в свойствах Заголовок на листе

![[../resources/ОВВК/ОВВК_38.jpg]]
# Редактирование отверстий

Если вдруг отверстие вышло больше или меньше, чем необходимо, можно поправить это вручную.

- На плане этажа найти отверстие
- Потянуть до границ труб за стрелочки выделенные на рисунке ниже

![[../resources/ОВВК/ОВВК_39.jpg]]

- В `ADSK_Отверстие_Ширина` добавить 100 (Значение отступа * 2)

Чтобы быстро найти отверстие на 3D виде нужно:

- Открыть 3D вид
- На плане этажа выделить нужное отверстие
- Во вкладке Изменить| Обобщенные модели → Вид нажать Рамка выбора

![[../resources/ОВВК/ОВВК_40.jpg]]

Готово!
