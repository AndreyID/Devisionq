# Возможные причины

Заполнился объем оперативной памяти или операционного диска.
# Решение - Исправить модель

## Шаг 1 - Синхронизировать

Чтобы синхронизировать открытую модель, освободите место на диске C:\ (D:\):

1. Удалите локальные копии (кроме сегодняшней даты) из папки с резервными копиями файлов Revit.
2. Очистите от лишних файлов папки:

- Загрузки
- Рабочий стол
- Корзину
- Мои документы

1. Удалите все файлы журналов (кроме сегодняшней даты) из каталога: %localappdata%\Autodesk\Revit\Autodesk Revit `<version>`\Journals

2. Синхронизируйтесь

3. Если синхронизироваться не удалось, очистите папку %temp% при открытом Revit по инструкции ниже.

## Шаг 2 - Устранить проблему

Чтобы устранить проблему:

1. Закройте Revit и другие продукты Autodesk
2. Очистите папку Temp, для этого:

- Скопируйте в проводник %Temp% (либо С:\USERS\Имя пользователя\AppData\Local\Temp)
- Выберите все файлы внутри папки, удалите через комбинацию клавиш Shift+Delete (безвозвратное удаление, минуя корзину). Для некоторых файлов в появляющихся ошибках нажмите "Пропустить"

3. Запустите программу Revit, откройте файл, при открытии закройте ненужные рабочие наборы.

4. Проводите чистку регулярно.
