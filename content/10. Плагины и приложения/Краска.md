# Цель

Внести в спецификации немоделируемые элементы крепления труб и окраску трубопроводов.
# Алгоритм работы

1. Ищет расчётное семейство в документе, при отсутствии загружает.

2. Получает все системы труб.

3. Получает все трубы из этих систем.

4. Сначала группирует их по параметру ADSK_Группирование.

5. Затем группирует их по диаметру.

6. Для каждой группы вида `ADSK_Группирование, диаметр` находит самую длинную трубу и делит её пополам.

7. Размещает в место разделение трубы расчётное семейство в место разделения трубы.

8. Заполняет параметр длины L = Сумма длин всех труб в м.

9. Заполняет параметр Тип_трубы:

     = 1, если имя трубы содержит "сталь"

     = 2, если имя трубы содержит "чугун"

     = 3, в остальных случаях

10. Заполняет параметр ADSK_Группирование (берётся из трубы).

11. Заполняет параметр DN = диаметр трубы.

12. Поворачивает семейство по направлению трубы.

13. Соединяет его с трубами, получившимися после разделения.

# Итог

В каждой из групп `ADSK_Группирование, диаметр` на самой длинной трубе размещено расчётное семейство с заполненными параметрами.
