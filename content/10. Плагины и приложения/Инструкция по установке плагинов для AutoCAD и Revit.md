> Статья описывает процесс установки плагинов для AutoCAD и Revit от Devision. Для Revit необходимо закрыть все открытые окна, установить плагин через **SetupDeVision.exe**, и обновить плагин после запуска. Для AutoCAD нужно закрыть приложение, разархивировать **DEVISION.bundle.rar** в указанные пути, используя WinRAR, и убедиться, что плагин загружается при запуске. Процесс повторяется для обновления.Cocoon AI Summary

# Устанавливаем плагин для Revit:

1. **ОБЯЗАТЕЛЬНО!** Перед установкой закрываем Revit
2. Открываем сервер с папками.
3. Заходим по пути: **_\\192.168.22.113\проекты\Библиотека Devision\06_BIM\Плагин\Setup_**
4. Запускаем файл **SetupDeVision.exe**.
5. Везде нажимаем далее и ждём окончания установки.
6. После запускаем **Revit**, всегда загружать и во вкладке **DEVISION** нажимаем кнопку обновление и обновляемся.
7. **Revit** перезапуститься сам (нужно просто подождать).

# Устанавливаем плагин для AutoCAD:

1. **ОБЯЗАТЕЛЬНО!** Перед установкой закрываем AutoCAD
2. Заходим по пути: **\\192.168.22.113\проекты\Библиотека Devision\06_BIM\Плагин\Плагин для автокада\2021**
3. Берём оттуда файл: **DEVISION.bundle.rar**
4. Разархивируем его в два пути с помощью **WinRAR** 
   Локальный диск (С:) \ Пользователи \ "..." \ %AppData% \ Autodesk \ ApplicationPlugins 
   Локальный диск (С:) \ ProgramData \ Autodesk \ ApplicationPlugins
5. После запускаем AutoCAD, всегда загружать
6. Для обновления плагина, если появилась более актуальная версия, проделать тот же процесс
