# Симптомы

При перемещении связанного файла и сохранения его площадки появляется следующая ошибка

![[../resources/03. Методичка BIM/BIM_19.jpg]]
# Возможные причины

Не выявлены
# Решение

Открываем связанную модель отдельно, для того чтобы создать локальный файл 

Переходим в сборку, удаляем связанную модель
Управление → Диспетчер связей → Revit → Связанная модель → Удалить

![[../resources/03. Методичка BIM/BIM_20.jpg]]

Добавляем локальную копию связанного файла
Управление → Диспетчер связей → Revit → Добавить → 
Путь к локальной копии → Размещение в зависимости от удобства и настроек → Открыть

![[../resources/03. Методичка BIM/BIM_21.jpg]]

Двигаем модель так, как она должна располагаться

Сохраняем положение
Настройка координат смотреть статью...

![[../resources/03. Методичка BIM/BIM_23.jpg]]

Все закрываем
Открываем локальную копию
Синхронизируем

Открываем сборку
Управление → Диспетчер связей → Revit → Связанная модель (лк) → 
Обновить из → Связанная модель с сервера

![[../resources/03. Методичка BIM/BIM_22.jpg]]
