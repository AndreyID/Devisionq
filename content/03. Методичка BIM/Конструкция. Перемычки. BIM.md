# Вставка

![[Пла_36 1.png]]

Плагин позволяет расставлять перемычки в проемы, а так же редактировать и создавать типы перемычек.

**Порядок действий:**

- Нажимаем  `Перемычки` → `Вставка`
  

- Выбираем требуемые проемы → Нажимаем `Готово` в левом верхнем углу
  
![[Пла_40 1.png]]

![[Пла_39 1.png]]

- В разделе семейство можно выбрать нужную перемычку

![[Пла_47 1.png]]

- Выбираем соответствующий типоразмер
  Если его нет:
  Меняем `Имя типа` и `Значение` параметров → `Сохранить тип`
  
  Пример наименования: `Пр-1_L50х5(110х7)_180_1250_1`
  
![[Пла_48 1.png]]

- Для сохранения нажимаем `Ок`
  
![[Пла_49 1.png]]
# Эскиз

![[Пла_37 1.png]]

- Перед использованием проверяем заполнение параметров

| Параметр      | Тип |
| ------------- | --- |
| Тип_Стены     | Тип |
| Толщина стены | Тип |

|     | Тип_Стены                                      |
| --- | ---------------------------------------------- |
| 1   | Кирпич                                         |
| 2   | Газоблок                                       |
| 3   | Утеплитель + Кирпич                            |
| 4   | Утеплитель + Газоблок                          |
| 5   | Составная стена (Кирпич + Утеплитель + Кирпич) |
| 6   | Составная стена (Кирпич + Утеплитель + Кирпич) |
| 7   | Составная стена (Кирпич + Зазор + Кирпич)      |
Толщины стен:
65; 75; 90; 100; 120; 180; 200; 250 


![[Пла_55 1.png]]

- Переходим в спецификацию Ведомость перемычек
  `АС` → `Перемычки` → `✔` → `✔_(АС)_Перемычки (ведомост_поэтажная)`

![[Пла_50 1.png]]

- Выбираем перемычки к которым требуется изображение

![[Пла_51 1.png]]

## Изображение

- Открываем файл `Перемычки рисунки.DWG`
  `\\192.168.22.113\проекты\Библиотека Devision\06_BIM\Шаблон_АР(АС)\Семейства\Перемычки\Картинки\Создание картинок перемычек`

- В рамке создаем требуемое изображение
  
- Нажимаем на инструмент `Печать`
  
![[Пла_60 1.png]]

- В разделе `Имя` выбираем `PublishToWeb PNG.pc3`
 ![[Пла_59 1.png]]

- Выставляем такие же значения как на картинке

![[пла_61 1.png]]

- Нажимаем на `Рамка<` и выбираем интересующую нас область

![[Пла_58 1.png]]

- Для сохранения нажимаем `Ок` и сохраняем в соответствующую перемычку
  `\\192.168.22.113\проекты\Библиотека Devision\06_BIM\Шаблон_АР(АС)\Плагины\library`

- Пример наименования: `1_250`, где  `1 - Тип стены`, `250 - Толщина стены`
  
## Текстовый документ

- Текстовый документ прикладывается рядом с изображением
  
![[пла_62 1.png]]

- Содержание
  
`#Имя вложенного семейства или параметра,отступ слева,отступ сверху,угол поворота`

- Пример наименования: `1_250`, где  `1 - Тип стены`, `250 - Толщина стены`
