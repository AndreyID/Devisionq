Правило наименования проектов
1. Стадия:
    АР_(ПК / К / Э / П / Р)
2. Часть здания: 
   П - Первый этаж
   Т - Типовой этаж 
   Тв - Типовой этаж (верх)
   Тн - Типовой этаж (низ)
   Ф - Фасад
3. Типы ориентации:
   М - Меридиональная
   У - Угловая
   Ш - Широтная
4. Наименование проекта
5. Тип строения:
   С - Секция. При наличии перепривязочных площадок указываются все площадки по возрастанию, например: С1.3_2.3_3.3 (нумерация в зависимости от проекта)
   Стр - Строение. Прим: Стр4
   К - Квартал. Прим: К1
   Паркинг. Паркинг1 (возможны площадки)
Общий формат наименования:
Стадия_Часть здания_Тип ориентацииИмя проектаТип строения
Краткий формат:
Стадия_Имя проекта_Тип строения

ВАЖНО: 
   1. Полное наименование справедливо для стадии Э, для следующих этапов (П / Р) применять краткое наименование. К примеру в стадии Р Тип строения указывается с одним номером секции, без перепривязочных площадок, т.к. оформление осуществляется для каждого отдельного здания.  
   2. Если проект загружен не на Revit Server, к наименованию обязательно добавляется версия Revit и указание, является ли проект файлом-хранилищем, например: R23_ФХ
ПРИМЕЧАНИЕ: 
   На начальном этапе полное и точное наименование может быть неочевидным, это нормально (не хватает полных данных). Важно внести всю доступную информацию о файле. Впоследствии ее можно дополнить.
   Для чего это все нужно? Такое наименование помогает ориентироваться среди файлов, понимать:
   -Какие это части здания (первые, типовые, фасады)
  - Какое положение у секций, ее ориентация
   -Какие у секций есть перепривязочные площадки
Также это упрощает поиск нужных секций в завершенных проектах для их использования в новых.
