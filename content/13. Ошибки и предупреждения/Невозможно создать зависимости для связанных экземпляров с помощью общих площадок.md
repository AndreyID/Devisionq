# Cимптомы

**Появляется предупреждение о необходимости удаления элементов модели.**  
  
- Текст ошибки: "Невозможно создать зависимости для связанных экземпляров с помощью общих площадок.".
- Текст ошибки eng: "It is not possible to create dependencies for related instances using shared sites."

![[../../resources/12. Часто задаваемые вопросы/Ошибки и предупреждения/Ош_66.webp]]
# Возможные причины

Сообщение появляется при попытке зафиксировать размерные линии, построенные между элементом открытой модели и элементом связанного файла, в который записаны общие координаты.
# Решение - Обновить связь

Сообщение можно проигнорировать, нажатием на кнопку "Ок", если требуется убрать это предупреждение, то есть два варианта решения:

1. Выбрать в диалоговом окне "Удалить зависимости", при этом удалятся элементы модели "зависимость", сами размерные линии останутся на месте.
2. Убрать общие координаты из связанного файла.
