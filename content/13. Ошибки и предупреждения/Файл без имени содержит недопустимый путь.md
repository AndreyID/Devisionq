# Cимптомы

- Проект не синхронизируется с файлом хранилища.
- При обновлении связи или открытии рабочего набора появляется ошибка.
- Появляется ошибка

- Текст ошибки: "файл без имени содержит недопустимый путь."
- Текст ошибки eng: "an unnamed file contains an incorrect path."

# Возможные причины

1. Наличие в проекте при совместной работе связей DWG или RVT, загруженных в проект не с сетевых дисков (сервера), а с локальных дисков (собственный рабочий стол, диск D, диск C).
2. Наличие в проекте связей DWG, у которых длина полного пути с указанием названия файла (с расширением) превышает 255 символов (ограничение ОС Windows).
3. Наличие в проекте связей RVT, у которых длина полного пути с указанием названия файла (с расширением), сохраненного на Revit Server превышает 138 символов.
4. Наличие в проекте связей RVT, в которых, в свою очередь, имеются связи с вышеописанными проблемами.
# Решение #1 - Обновить связь

1. Обновите связь через диспетчер связей или через диспетчер проекта с помощью функции "Обновить из...".
2. Если после обновления связи через "Обновить из..." ошибка при ее обновлении повторяется, то решите проблему в самой связи методом описанным в разделе "Устранение проблемы" данной инструкции.
# Решение #2 - Закрыть проблемную связь

Для того, чтобы открыть рабочий набор, нужно понять, в какой из связей этого набора заключается проблема:

1. Выгрузите все связи данного рабочего набора через диспетчер связей или через диспетчер проекта.
2. Откройте необходимый рабочий набор, затем поочередно обновите выгруженные связи.
3. Связь, при обновлении которой возникает ошибка, обновите через диспетчер связей или через диспетчер проекта с помощью функции "Обновить из...".
4. Если после обновления связи через "Обновить из..." ошибка при открытии рабочего набора повторяется, то решите проблему в самой связи методом описанным в разделе "Устранение проблемы" данной инструкции.
# Решение #3 - Закрыть рабочие наборы

Для того, чтобы синхронизировать файл:

1. Закройте все рабочие наборы.
2. Синхронизируйтесь.
# Решение #4 - Пересохранить  
  
Если файл не синхронизируется, то:

1. Сохраните файл через "Сохранить как" в любое место на ПК.
2. Закройте файл.
3. Перезапустите Revit.
4. Откройте файл с директории, куда сохранили его в п.2.
5. Синхронизируйтесь.
# Устранение проблемы

Если ошибка повторяется при дальнейшей работе в модели, проверьте модель на наличие связей RVT и DWG, о которых описано в причинах данной проблемы.

1. При наличии связей DWG или RVT с локальных дисков:

- Удалите проблемную связь.
- Пересохраните файл связи в папке с общим доступом (на сервере).
- Загрузите связь в проект.
- Если после устранения проблем со связями ошибка повторяется, перезапустите Revit.

2. При наличии связей DWG или RVT с длиной пути, превышающей 255 символов:

- Удалите проблемную связь.
- Уменьшите количество подпапок или сократите имя (папок/моделей), или перенесите файл на одну или несколько подпапок выше.
- По итогу длина пути до исходного файла (с указанием имени файла и его расширением) не должна превышать 255 символов (в данную цифру входят и видимые и невидимые-системные символы Windows).
- Если после устранения проблем со связями ошибка повторяется, перезапустите Revit.

3. Связи RVT с Revit Server с длиной пути, превышающие 138 символов:

- Удалите проблемную связь.
- Измените имя файла связи, таким образом, чтобы длина пути с указанием имени файла и его расширением не превышала 138 символов.
- Если после устранения проблем со связями ошибка повторяется, перезапустите Revit.

4. Связи RVT, в которых, имеются проблемные связи:

- Исправьте проблему в файле связи RVT по предложенным решениям выше.
- Если после устранения проблем со связями ошибка повторяется, перезапустите Revit.
# Комментарии

1. Данная ошибка запоминается самим Revit и может повторяться в разных проектах, если они были открыты в одном сеансе Revit, поэтому важно при появлении данной ошибки и после устранения потенциальных проблем описанных выше, перезапускать программу.
2. Очистка папки %Temp% также помогает решить эту проблему, поэтому важно проводить чистку папки %Temp% регулярно.

Для очистки папки %Temp%:

- Закройте Revit.
- Скопируйте в проводник %Temp% (либо C:\USERS\Имя пользователя\AppData\Local\Temp).
- Выберите все файлы внутри папки, удалите через комбинацию клавиш Shift+Delete (безвозвратное удаление, минуя корзину). Для некоторых файлов в появляющихся ошибках нажмите "Пропустить"
