# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Не удалось открыть связанный документ ".....". Связь будет выгружена".
- Текст ошибки eng: "Cannot open linked document ".....". The link will be unloaded" .

![[../resources/13. Ошибки и предупреждения/Ош_44.webp]]
# Возможные причины

- Слишком большой вес и объем внедряемой связи.
- Внутри внедряемой связи имеются поврежденные семейства.
- Конфликт параметров из основного файла и файла связи по причине разных типов данных одноимённых параметров. Например, в основном файле один параметр имеет тип данных "Длина", а в файле связи тип "Денежная единица".
# Решение #1 - Открыть с проверкой

1. Откройте проблемную связь с проверкой.
2. Синхронизируйтесь.
3. Закройте проблемную связь.
4. Обновите связь с помощью "Обновить из"… в исходном проекте.

![[../resources/13. Ошибки и предупреждения/Ош_45.webp]]
# Решение #2 - Пересохранить файл хранилище

Замените файл хранилище проблемного связанного файла. Для этого:

1. Убедитесь, что все участники синхронизировались и закрыли локальные копии.
2. Откройте связанный файл, с отсоединением от файла хранилища и проверкой.
3. Сохраните файл поверх файла хранилища через "Сохранить как" и выберите путь к модели. После этого сохраненный вами файл будет считаться файлом хранилища.
4. Освободите все забранные рабочие наборы.
5. Синхронизируйтесь.
6. Закройте файл.
7. Обновите пересозданную связь в вашем проекте с помощью "Обновить из…".
