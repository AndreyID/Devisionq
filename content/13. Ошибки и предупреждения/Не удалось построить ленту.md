# Возможные причины

Использовано максимально допустимое количество вкладок в Revit.
# Решение #1 - Удалить лишние плагины

Удалите лишние плагины Revit, которые формируют вкладки на ленте. Для этого:

- Панель управления - Удаление программ
- Через удаление файлов плагинов из папки %programdata%\Autodesk\Revit\Addins\<version>
- Через удаление файлов плагинов из папки %appdata%\Autodesk\Revit\Addins\<version>

  

Дополнительно проверьте:

- C:\ProgramData\Autodesk\ApplicationPlugins - эту папку можно использовать для надстроек, которые предназначены для нескольких программ или версий.
- C:\Program Files\Autodesk\Revit <version>\AddIns - эта папка используется для внутренних надстроек, но некоторые более ранние версии надстроек могут быть загружены в нее.
