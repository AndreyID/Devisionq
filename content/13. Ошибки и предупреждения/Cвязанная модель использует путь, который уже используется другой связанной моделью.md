# Cимптомы

**При попытке подгрузить связь, появляется предупреждение.**  
  
- Текст ошибки: "Связанная модель использует путь который уже используется другой связанной моделью".
- Текст ошибки eng: "Linked model is using a path already in use by another linked model".

![[Ош_123.webp]]
# Возможные причины

Вероятно, в модель, которую вы хотите загрузить, загружена связью ещё одна модель, которая или уже загружена в основную модель или вложена в какую-то из других связей основной модели.
# Решение - Переключить тип связи

1. Откройте модель, которую хотели загрузить.
2. Через диспетчер проекта или через диспетчер связей, перейдите в настройки приложенных связей.
3. Переключите тип связи на "Наложение".
4. Синхронизируйтесь.
5. Откройте основную модель и попробуйте загрузить связь повторно.
