# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Этот документ содержит макросы. Выберите одну из следующих возможностей."
- Текст ошибки eng: "This document contains macros. Select one of the following options."

![[../resources/13. Ошибки и предупреждения/Ош_135.webp]]
# Возможные причины

В файле присутствуют макросы.

Макросы - это некий программный код, который внедряется в проект, с помощью которого можно автоматизировать разные процессы в Revit.
# Решение - Выбрать один из вариантов

1. Выберите "Отключить макросы для данного документа", например, если вы не знаете разработчика этих макросов. После этого макросы в данном документе запускаться не будут.

2. Выберите "Включить макросы данного документа", если вы знаете разработчика этих макросов и он вам нужен для использования. После этого в данном документе макросы можно будут доступны для запуска.
