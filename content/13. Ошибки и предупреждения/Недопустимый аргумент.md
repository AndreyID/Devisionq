# Возможные причины

Проблема не связана с самим ревитом и характерна для изменениях в настройках Windows в целом.
# Варианты решения

Виной может быть как одна причина, так и их комплекс. Ниже приведены варианты действий, каждое из которых может решить проблему. Между каждым из них рекомендуется выполнять перезагрузку компьютера, пробовать запустить ревит и, в случае, если проблема не решилась, то переходить к следующему варианту решения.

  1. Попробуйте открыть модель зайдя в Windows под другим пользователем.
2. Обновите Windows.
3. Если незадолго до появления этой ошибки вы устанавливали какие-то приложения, то по возможности удалите это приложение.
4. Обновите Revit
5. Переустановите Revit (решение на крайний случай, т.к. возможно будет проще работать под другим пользователем)
