# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Не удалось внедрить выбранные связи".
- Текст ошибки eng: "Unable to blind the selected links".

![[../resources/13. Ошибки и предупреждения/Ош_37.webp]]
# Возможные причины

1. Слишком большой вес и объем внедряемой связи.
2. Внутри внедряемой связи имеются поврежденные семейства.
3. Конфликт параметров из основного файла и файла связи по причине разных типов данных одноимённых параметров. Например, в основном файле один параметр имеет тип данных "Длина", а в файле связи тип "Денежная единица".
# Решение #1 - Создать копию связи

1. Создайте копию связанного файла себе на ПК, для этого: Откройте внедряемую связь с отсоединением и проверкой; Выберите "Отсоединить и не сохранять рабочие наборы", чтобы все элементы были видимы.

![[../resources/13. Ошибки и предупреждения/Ош_38.webp]]

2. Сохраните отсоединенный файл через "Сохранить как" себе на ПК.3. Откройте этот файл и методом исключения найдите проблемные семейства:

последовательно порциями удаляйте семейства, каждый раз синхронизируясь и внедряя данную связь в ваш проект.

после удаления поврежденных семейств, связь в одну из итераций внедрится и вы поймете, в каких семействах заключалась проблема.

4. Закройте копию файла. Откройте оригинал связанного файла и удалите там поврежденные семейства, из пункта 3.

5. Внедрите связанный файл.
# Решение #2 - Удалите параметры

В данном случае - причиной является конфликт параметров из основного файла и файла связи по причине разных типов данных одноимённых параметров.

Решите проблему с параметрами по инструкции: "Удаление параметров из проекта".
# Комментарии

Не используйте функцию "Внедрить связь" для больших тяжелых связей.
