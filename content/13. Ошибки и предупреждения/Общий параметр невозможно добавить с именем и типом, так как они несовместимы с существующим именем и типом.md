# Cимптомы

**При копировании видов из другого проекта, при загрузке семейства возникает ошибка.**  
  
- Текст ошибки: "Общий параметр "..." невозможно добавить с именем "..." и типом "...", так как они несовместимы с существующим именем "..." и типом "...".".
- Текст ошибки eng: "The shared parameter "..." cannot be added with name "..." and tipe"...", because it conflicts with the existing name "..." and tipe "...".""

![[../resources/13. Ошибки и предупреждения/Ош_73.webp]]
# Возможные причины

1. Возникает конфликт разных типов данных у одного общего параметра.
2. Копирование семейств из старых проектов в новые.
3. Последствия изменения параметра в ФОП ( Файле общих параметров).
# Решение - Удалить параметры

Удалите параметры стандартным способом через "Параметры проекта" со вкладки "Управление". Перейдите на вкладку "Управление", выберите "Параметры проекта". Найдите нужный параметр, выберите его и нажмите "Удалить".
## Вариант 1

Удалите параметры стандартным способом через "Параметры проекта" со вкладки "Управление".

1. Перейдите на вкладку "Управление", выберите "Параметры проекта".
2. Найдите нужный параметр, выберите его и нажмите "Удалить".
## Вариант 2

Если нужные параметры не отображаются в окне "Параметры проекта" или после удаления первым способом ошибка все равно появляется, то удалите параметры с помощью инструмента "Revit Lookup".

1. Установите надстройку "Revit Lookup", если она у вас отсутствует. https://github.com/jeremytammik/RevitLookup
2. Перейдите на вкладку "Надстройки", в выпадающем списке "Revit Lookup" выберите функцию "Snoop DB...".
3. Найдите строчку "SharedParameterElement" и раскройте выпадающий список.
4. Найдите наименование параметра, который вызывает ошибку и скопируйте его ID.

![[../resources/13. Ошибки и предупреждения/Ош_74.webp]]

5. Выберите данный параметр в проекте с помощью инструмента "Выбрать по коду" со вкладки "Управление". Вставьте скопированный ранее ID в предложенное там окно, нажмите "ОК".

6. Убедитесь, что параметр выбран, удалите параметр.

Добавьте корректные параметры в проект заново через "Параметры проекта" со вкладки "Управление".

Для этого:

1. Перейдите на вкладку "Управление", выберите "Параметры проекта".
2. Добавьте необходимый Общий параметр, проставив необходимые Категории для данного параметра.
