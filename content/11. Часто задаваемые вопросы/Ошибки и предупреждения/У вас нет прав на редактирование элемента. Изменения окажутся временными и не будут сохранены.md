# Cимптомы

**При попытке внести изменения в модель появляется предупреждение.**  
  
- Текст ошибки: "У вас нет прав на редактирование элемента. Изменения окажутся временными и не будут сохранены".
- Текст ошибки eng: "You do not have permission to edit the element".

![[../../resources/Ошибки/Ош_125.webp]]
# Возможные причины

В результате совместной работы появились элементы с неоднозначной информацией о заёмщике.
# Решение - Синхронизироваться

1. Необходимо, чтобы все пользователи последовательно синхронизировались с освобождением рабочих наборов.
2. Пользователь, у которого возникает ошибка, должен синхронизироваться последним.
