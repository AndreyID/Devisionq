# Cимптомы

1. Файл не открывается
2. Revit аварийно закрывается или при закрытии файла постоянно появляется предупреждение
3. Revit аварийно закрывается
4. Появляется предупреждение

- Текст ошибки: "Программа "Autodesk Revit" не работает. Возникшая проблема привела к прекращению работы программы. Windows закроет эту программу, а если есть известный способ устранения проблемы, уведомит вас об этом."
- Текст ошибки eng: "Autodesk Revit has stopped working. A problem caused the program to stop working correctly. Windows will close the program and notify you if a solution is available."

![[Ош_98.webp]]
# Возможные причины

1. Наличие поврежденных элементов модели.
2. Накопившиеся ошибки модели.
3. Некорректно работающие плагины, надстройки.
# Решение #1 - Открыть с проверкой

1. Выделите в проводнике файл
2. Установите галочку "Проверить"
3. В появившемся предупреждении нажмите "Да"

![[Ош_99.webp]]
# Решение #2 - Закрыть рабочие наборы

1. Выделите в проводнике файл
2. Установите галочку "Проверить"
3. В появившемся предупреждении нажмите "Да"
4. Рядом с кнопкой "Открыть" нажмите на стрелку вниз и выберите "Задать"

![[Ош_100.webp]]

5. Выберите все рабочие наборы, кроме того, в котором находятся общие уровни и сетки и нажмите "Закрыть".

![[Ош_101.webp]]

6. После открытия файла выгрузите все связи через диспетчер связей, откройте все рабочие наборы, затем поочередно обновите выгруженные связи.

7. Удалите связь, при обновлении которой возникают проблемы (ошибки).

8. Отдельно откройте с проверкой и закрытыми рабочими наборами файл удаленной связи и синхронизируйтесь, после чего закройте файл связи.

9. В рабочий файл заново добавьте эту связь.

10. Синхронизируйтесь.
# Решение #3 - Обновить revit

Аварийное завершение Revit при закрытии файла может говорить о конфликте настроек или некорректной установке программы в целом.

Попробуйте:

- Установить обновление для Revit (Например, если используете 2019 версию, установите update 2019.2.6)
- Отключить плагины, которые пакетом устанавливаются при установке Revit): Перенесите из папки C:\ProgramData\Autodesk\Revit\Addins\<version> все файлы с расширением .addin.
- Когда проблема пропадет, переносите обратно по одному файлу и проверяйте, возникнет ли предупреждение. Как только предупреждение вновь появится, обновите файл .addin, после переноса которого в Revit возникло предупреждение.
