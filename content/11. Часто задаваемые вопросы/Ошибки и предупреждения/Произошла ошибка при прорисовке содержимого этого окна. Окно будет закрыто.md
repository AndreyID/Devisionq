# Cимптомы

При открытии **второго** файла в одном сеансе Revit появляется предупреждение и программа закрывается.

- Текст ошибки: "Произошла непоправимая ошибка. Программа будет закрыта. Все ваши данные недавно были сохранены, поэтому файлы для восстановления создавать не требуется."
- Текст ошибки eng: "An unrecoverable error has occurred. The program will now be terminated. All of your data has been recently saved, so there is no need to create recovery files."

# Возможные причины

На компьютере недостаточно места для полноценной работы Revit.
# Решение #1 - Очистить temp

1. Закройте Revit и другие открытые продукты Autodesk.
2. Очистите диск:

- Очистите папку с резервными копиями файлов Revit
- Очистите папку Temp, для этого:

Скопируйте в проводник %Temp% (либо C:\USERS\Имя пользователя\AppData\Local\Temp)

Выберите все файлы внутри папки, удалите через комбинацию клавиш Shift+Delete (безвозвратное удаление, минуя корзину). Для некоторых файлов в появляющихся ошибках нажмите "Пропустить"

- Очистите папку Journals C:\USERS\Имя пользователя\AppData\Local\Autodesk\Revit\Autodesk Revit `<version>`\Journals

3. Откройте файл с проверкой.
