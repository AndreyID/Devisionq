# Cимптомы

1. Файл не открывается
2. Revit аварийно закрывается
3. Появляется предупреждение:
## Вариант 1

- Текст ошибки: "Произошла непоправимая ошибка. Программа будет закрыта. Все ваши данные недавно были сохранены, поэтому файлы для восстановления создавать не требуется."
- Текст ошибки eng: "An unrecoverable error has occurred. The program will now be terminated. All of your data has been recently saved, so there is no need to create recovery files."

![[../../resources/Ошибки/Ош_102.webp]]
## Вариант 2

- Текст ошибки: "Произошла серьезная ошибка. Текущая операция прервана."
- Текст ошибки eng: "A serious error has occurred. The current action has been cancelled."

![[../../resources/Ошибки/Ош_103.webp]]
## Вариант 3

- Текст ошибки: "Ошибка программы привела к непредвиденному закрытию Revit ... ."
- Текст ошибки eng: "A software problem has caused Revit ... to close unexpectedly."

![[../../resources/Ошибки/Ош_104.webp]]
# Возможные причины

1. Наличие поврежденных элементов модели.
2. Накопившиеся ошибки модели.

# Решение #2 - Открыть с закрытием рабочих наборов

1. При открытии выберите "Задать"

![[../../resources/Ошибки/Ош_106.webp]]

2. Закройте все рабочие наборы, кроме того, в котором находятся общие уровни и сетки

![[../../resources/Ошибки/Ош_107.webp]]

3. После открытия файла поочередно обновите выгруженные связи.

4. Удалите связь, при обновлении которой возникают проблемы (ошибки).

5. Отдельно откройте с проверкой и закрытыми рабочими наборами файл удаленной связи и синхронизируйтесь, после чего закройте файл связи.

6. В рабочий файл заново добавьте эту связь.

7. Синхронизируйтесь.
