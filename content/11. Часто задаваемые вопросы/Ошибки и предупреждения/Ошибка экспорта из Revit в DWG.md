# Cимптомы

**При экспорте в .dwg из Revit появляется ошибка.**  
  
- Текст ошибки: "Не удалось создать ....dwg, или файл уже используется. Закройте файл и нажмите "ОК"."
- Текст ошибки eng: "Can't create ....dwg, or the file is already in use. Please close file and press "OK"."

![[../../resources/Ошибки/Ош_53.webp]]
# Возможные причины

- Длинное название создаваемого DWG файла или его путь.
- Отсутствие доступа к папкам на диске, куда производится сохранение файла.
# Решение #1 - Изменить тип связи

1. Сократите название файла.
2. При экспорте выберите “Автоматически - Короткое”.
3. Если не поможет, экспортируйте на рабочий стол.
4. Перенесите в нужную папку.

![[../../resources/Ошибки/Ош_54.webp]]
# Решение #2 - Пересохранить на другом диске

Сохраните файл на другом диске. Для этого на этапе выбора пути сохранения файла нужно указать путь на нужный диск.
