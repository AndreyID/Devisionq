# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Приложению Revit не удалось запустить команду внешнее приложение "...". Обратитесь в соответствующую службу поддержки. Revit содержит следующую информацию по данной службе: ... ."
- Текст ошибки eng: "Revit Cannot run the external application "Collaborate". Contact the provider for assistance. Information they provided to Revit about their identity: ... ."

![[../../resources/Ошибки/Ош_92.webp]]
# Возможные причины

В Revit используется устаревшая версия внешнего приложения/плагина, либо поврежден файл внешнего приложения/плагина.
# Решение - Выполнить инструкцию

Обновление настроек Revit:

1. Запустите диспетчер задач и завершите все процессы Revit.

![[../../resources/Ошибки/Ош_93.webp]]

2. Удалите лишние сторонние плагины Revit, которые формируют вкладки на ленте:

- Через Панель управления - Удаление программ
- Через удаление файлов плагинов из папки %Appdata%\Autodesk\Revit\Addins\[версия]
- Через удаление файлов плагинов из папки C:\ProgramData\Autodesk\Revit\Addins\[версия]

Дополнительно проверьте:

- C:\ProgramData\Autodesk\ApplicationPlugins - эту папку можно использовать для надстроек, которые предназначены для нескольких программ или версий.
- C:\Program Files\Autodesk\Revit (версия)\AddIns - эта папка используется для внутренних надстроек, но некоторые более ранние версии надстроек могут быть загружены в нее.

3. После этого запустите Revit.

4. Может появиться окно, запрашивающее разрешение на загрузку внешнего приложения.

Если вы уверены в данной надстройке/плагине, то выберите:

- "Всегда загружать" и надстройка загрузится для использования в Revit.

Если вы не уверены или загружать настройку/плагин не нужно, то выберите:

- "Не загружать".
