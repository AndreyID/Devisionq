# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Связь не может быть обновлена, поскольку она загружена в другом открытом документе."
- Текст ошибки eng: "The link cannot be updated because it is loaded in another open document."

![[Ош_34.webp]]
# Возможные причины

В текущем окне Revit открыт ещё один файл в котором уже загружена связь, которую нужно обновить.
# Решение #1 - Обновить связь

1. Закройте второй файл.
2. Откройте диспетчер связей и обновите связь.

![[Ош_35.webp]]
# Решение #2 - Выгрузить связь

Если не предполагается копирование элементов между открытыми файлами.

1. Перейдите к активному виду во втором файле (Ctrl+Tab - последовательное переключение видов, Ctrl+Shift+Tab - переключение видов в обратном порядке).
2. Откройте диспетчер связей и выгрузите связанный файл Для меня.
3. Перейдите к активному виду первого файла, откройте диспетчер связей и обновите связь.
