# Cимптомы

**При открытии файла Revit появляется предупреждение.**  
  
- Текст ошибки: "Изменить элемент невозможно до тех пор, пока пользователь "..." не сохранит элемент в хранилище и не освободит его. После этого необходимо обновить файл из хранилища."
- Текст ошибки eng: "Can't edit the element until "..." resaves the element to central and relinquishes it and you Reload Latest."

![[../../resources/Ошибки/Ош_20.webp]]
# Возможные причины

При совместной работе пользователи занимают элементы и рабочие наборы. Когда нет возможности связаться с пользователем, занявшим рабочие наборы, используйте данное решение.
# Решение - Синхронизироваться

Освободите рабочие наборы, занятые другим пользователем:

1. Запустите параллельно еще один сеанс Revit.
2. Закройте главную страницу Revit.
3. Перейдите в "Файл" → "Параметры"→ вкладка "Общие".
4. В поле "Имя пользователя" введите имя пользователя, который занял рабочий набор, нажмите "ОК".

![[../../resources/Ошибки/Ош_21.webp]]

5. Откройте проект.

6. Перейдите на вкладку "Совместная работа" и нажмите на кнопку "Освободить все забранные".

7. Синхронизируйтесь, закройте локальный файл.

8. Снова перейдите в меню "Параметры" и измените имя пользователя на предыдущее значение, своё.

9. В первом сеансе Revit, в котором рабочие наборы были заняты, также синхронизируйтесь.
