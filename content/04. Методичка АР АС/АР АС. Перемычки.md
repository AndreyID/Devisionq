# Параметры

### Основное семейство:

| Параметр       | Тип      | Назначение                                    |
| -------------- | -------- | --------------------------------------------- |
| ADSK_Марка     | Тип      | Марка перемычки (например, **Пр-1**)          |
| Dv_Номер этажа | Экземляр | Номер этажа, на котором расположена перемычка |
| Изображение    | Экземляр | Изображение (графическое представление)       |
| LintelImage    | Экземляр | Изображение (графическое представление)       |
### Вложенные семейства:

| Параметр       | Тип      | Назначение                     |
| -------------- | -------- | ------------------------------ |
| Марка          | Экземляр | Позиция в спецификации         |
| Dv_Номер этажа | Экземляр | Номер этажа                    |
| ADSK_Марка     | Экземляр | Связанна с основным семейством |
# Спецификации

### Вспомогательные спецификации

`Диспетчер проекта` → `Ведомости/Спецификации` → `АС` → `Перемычки` → `✔`

| Название спецификации                | Назначение                                      |
| ------------------------------------ | ----------------------------------------------- |
| `✔_(АС)_Перемычки (Dv_Номер этажа)`  | Быстрое проставление параметра `Dv_Номер этажа` |
| `✔_(АС)_Перемычки (проверочная)`     | Проверки заполнения параметров                  |
| `✔_(АС)_Перемычки (поэтажная)_Шапка` | Отдельная шапка спецификации                    |

### Спецификация: Основное семейство

`Диспетчер проекта` → `Ведомости/Спецификации` → `АС` → `Перемычки` → `✔`

`✔_(АС)_Перемычки (ведомост_поэтажная)`

**Настройка:**

- Категория: Каркас несущий

- Фильтр: 
  `Группа модели` равно «Перемычки составные»
  `Тип` не содержит «пм»
  
- Поля: `ADSK_Марка`, `Dv_Номер этажа`, `LintelImage`

![[../resources/02. Методичка Общая/АС_НР_28 1.png]]
### Спецификации: Вложенное семейство

`Диспетчер проекта` → `Ведомости/Спецификации` → `АС` → `Перемычки` → `✔`

`✔_(АС)_Перемычки (поэтажная)_Арм`
`✔_(АС)_Перемычки (поэтажная)_Детали`
`✔_(АС)_Перемычки (поэтажная)_Металлические`
`✔_(АС)_Перемычки (поэтажная)_Полистироллбетонные`

**Настройка:**

- Категория: Каркас несущий

- Фильтр: 
  `Группа модели` равно «Перемычки»
   
- Поля: `Марка`, `Обозначение`, `ADSK_Наименование`, `Наименование`,  `Dv_Номер этажа`, `ADSK_Обозначение`
